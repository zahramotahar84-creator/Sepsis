# Sepsis Early Detection System 🏥
This project focuses on the early prediction of sepsis using patient biometric data to reduce mortality rates through timely medical intervention.

### 🛠 Tech Stack
- **Language:** Python
- **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib
- **Model:** Classification models (Random Forest / Logistic Regression)

### 📈 Key Achievements
- Implemented a predictive pipeline for analyzing vital signs.
- Achieved high sensitivity to ensure critical cases are not missed.
- Focused on minimizing False Negatives to prioritize patient safety.


# سیستم پیش‌بینی زودهنگام سپسیس 🏥
هدف این پروژه، تشخیص زودهنگام بیماری سپسیس با استفاده از داده‌های بیومتریک بیماران است تا با تشخیص سریع‌تر، نرخ مرگ‌ومیر کاهش یابد. 

### 🛠 ابزارهای مورد استفاده
- **زبان:** پایتون
- **کتابخانه‌ها:** Scikit-learn, Pandas, NumPy
- **مدل:** الگوریتم‌های طبقه‌بندی (مانند Random Forest) 

### 📈 دستاوردهای کلیدی
- پیاده‌سازی خط لوله‌ای برای تحلیل علائم حیاتی بیمار.
- دستیابی به حساسیت (Sensitivity) بالا برای اطمینان از شناسایی تمام موارد بحرانی.
- تمرکز بر کاهش «منفی‌های کاذب» (False Negatives) برای حفظ جان بیماران.
